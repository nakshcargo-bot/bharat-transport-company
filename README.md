## Backend administrator bootstrap

To create the initial backend administrator, configure `INITIAL_ADMIN_USERNAME` and
`INITIAL_ADMIN_PASSWORD` in the backend environment before starting the server.
Set `INITIAL_ADMIN_EMAIL` when staff will sign in with an email address; otherwise
they can sign in using the configured username.
The server will not create an administrator with a built-in default password.
